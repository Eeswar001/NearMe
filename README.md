# Ex04 Places Around Me
## Date: 

## AIM
To develop a website to display details about the places around my house.

## DESIGN STEPS

### STEP 1
Create a Django admin interface.

### STEP 2
Download your city map from Google.

### STEP 3
Using ```<map>``` tag name the map.

### STEP 4
Create clickable regions in the image using ```<area>``` tag.

### STEP 5
Write HTML programs for all the regions identified.

### STEP 6
Execute the programs and publish them.

    <h2>Villupuram Railway Junction (VM)</h2>
    <p>Villupuram Junction is one of the major railway hubs in Tamil Nadu.</p>

    <ul>
        <li><strong>Station code:</strong> VM</li>
        <li>Managed by Southern Railway, Tiruchirappalli division.</li>
        <li>The station has 6 platforms and handles many express and passenger trains daily.</li>
    </ul>

    <h3>Connecting Routes</h3>
    <ul>
        <li>Chennai (via Chengalpattu)</li>
        <li>Tiruchirappalli (Trichy)</li>
        <li>Puducherry</li>
        <li>Katpadi (Vellore)</li>
        <li>Tiruvannamalai / Vellore route</li>
    </ul>

    <p>Because of these routes, Villupuram serves as a central point for travelling to South, North, and Central Tamil Nadu.</p>
    <p>Many long-distance trains pass through or originate from here.</p>

    <h3>Modernization</h3>
    <p>The junction is currently being modernized under the Amrit Bharat Station Scheme.</p>

    <ul>
        <li>New terminal building</li>
        <li>Better waiting halls</li>
        <li>Improved platforms</li>
        <li>Lift/escalator facilities</li>
        <li>Wider foot-over-bridges</li>
    </ul>

    <p>Villupuram Junction is the main rail link for Puducherry.</p>
    <p>It handles lakhs of passengers every month and is one of the busiest stations in the region.</p>
